● OBJECTIVE FACTS ONLY OpenDota API
Вставь Match ID из Dota 2 (История → Копировать ID) или ссылку dotabuff/opendota. Данные тянутся с OpenDota — без ключа. Если API не отвечает, включится демо-катка. Можно анализировать любую катку: паб, турбо, ranked.
Как считаем «заруинил»: 6 объективных факторов → общий Ruin Score 0–100. Чем выше — тем больше заруинил. Учитываем: смерти, фарм (GPM/LH), урон, участие в драках, вижен/варды (для саппов), слив преимущества / смерти после 30 мин. Никаких «он пикнул Пуджа» — только цифры из матча. Вес факторов разный для коров и саппортов.
