# DOTA RUINER — кто заруинил катку

Веб-разбор матча Dota 2: по ID матча показывает, **кто заруинил** игру, **кто её тащил** и почему.

Бэкенд не нужен — сайт полностью статический, данные берутся напрямую из
[OpenDota API](https://docs.opendota.com/).

## Как пользоваться

1. Открыть сайт.
2. Вставить ID матча (цифры из ссылки на матч в Dota 2 / OpenDota).
3. Получить вердикт: большие карточки «кто заруинил» и «кто тащил», а ниже — разбор остальных игроков.

Работает и ссылка вида `https://<user>.github.io/<repo>/#9046500720`.

## Как считается Ruin Score (0–100)

| Фактор | Вес | Логика |
| --- | --- | --- |
| Смерти | 30 | тем больше, чем выше смертность относительно команды |
| Фарм | 25 | GPM и LH/мин против ожиданий по роли |
| Урон | 20 | DPM против ожиданий по роли |
| Участие | 15 | доля командных убийств с участием героя |
| Вижен / Экономика | 15 | варды, стэки, лишние траты, buyback |
| Лив / АФК | +20 | штраф за выход из игры |

**Impact Score (0–100)** — отдельная метрика «кто тащил»: участие (30), убийства/мин (20),
урон/мин (20), фарм (10), башни (8), хил (8), выживаемость (14).

Факторы Вижен и Buyback пропускаются, если OpenDota не вернул эти данные
(для публичных матчей они часто отсутствуют) — тогда герой не штрафуется за незнание.

Роли (core / mid-off / support) определяются автоматически по GPM внутри команды,
поэтому сравнение идёт с ожиданиями именно для этой роли.

## Локальный запуск

```bash
node server.js        # http://localhost:4174
```

`server.js` — это только локальный дев-сервер и прокси к OpenDota (браузерные
запросы к API иногда блокируются Cloudflare). Для деплоя он не требуется.

## Деплой

Статический сайт, публикуется через GitHub Pages из корня репозитория
(ветка `main`, папка `/ (root)`). Билд не нужен.

## Структура

- `index.html` — весь сайт: разметка, стили и логика (vanilla JS, без зависимостей)
- `server.js` — локальный сервер + прокси к OpenDota (для разработки)
